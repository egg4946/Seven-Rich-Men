# Seven Rich Men — Design System

> superdesign-skill の規約に従い、UI を作る前に読む設計の正本。
> ビジュアルの基盤は melta UI(`references/melta-ui/DESIGN.md`)。ゲーム固有の部品と、
> melta から意図的に外れる点はこのファイルに書く。ルールの正本は `docs/RULES.md`。

## 1. Product context

| 項目 | 内容 |
|---|---|
| 何を作るか | 七並べ × 大富豪の数字効果のブラウザ対戦カードゲーム |
| 目指す体験 | ゴッドフィールドのような手軽さ。URLを開く → 名前を入れる → すぐ遊べる |
| 対象端末 | スマホ縦持ち(375px〜)とPC。どちらも同じ画面で遊べること |
| 現在の範囲 | CPU対戦(ソロ)。オンライン対戦は後で追加する |
| 主な利用者 | ルールをまだ覚えていない友人同士。遊びながら効果を覚えられる必要がある |

### 画面と主な流れ

1. **タイトル** — 名前、CPUの人数(2〜5人)、CPUの強さを選んで開始。ルールを確認できる
2. **対戦** — 場を見て、手札を選び、出す / パスする。効果の選択や宣言はその場で答える
3. **結果** — 順位と、上がり / 生き残り / 脱落 / 強制敗北 の区分。もう一度 or タイトルへ

### JTBD

- 自分の番に「何を出せるか」「出すと何が起きるか」がすぐ分かる
- CPUの番に「何が起きたか」を見逃さない(効果の通知とログ)
- 制限時間の残りが分かる(雀魂式の基本時間 + 持ち時間)

## 2. Visual direction

melta UI の Brand Identity をそのまま採用する: **"声を張らずに伝わる UI"**。
Quiet Precision / Breathable / Flat & Layered / Subtle Warmth。

カードゲームにありがちな緑のフェルト、金色の装飾、ネオン、グラデーションは使わない。
明るいグレーの背景に白いカードが並ぶ、静かで読みやすい卓にする。主役はカードと場。

**例外: 演出レイヤー。** 効果の発動・上がり・対戦の開始と終了は、一瞬だけ派手に見せて盛り上げる
(カットインの帯、閃光、紙吹雪)。ここだけは効果ごとの色(sky / red / violet / emerald / amber / gold)と
グラデーションを使ってよい。演出は必ず数秒以内に消え、常に見える UI(パネル・カード・場)は静かなまま保つ。

- ライトモードのみ
- 色は **背景(gray-50 / white)・アクセント(primary)・テキスト(slate)** の3色を基本にする
- 例外: トランプのスートの赤(♥♦ = `red-600`)は UI の色ではなくカードの内容として扱う

## 3. Tokens(melta UI から)

### Color

| 用途 | 値 |
|---|---|
| primary-50 / 100 / 200 | `#f0f5ff` / `#dde8ff` / `#c0d4ff` |
| primary-500(CTA・手番・選択) | `#2b70ef` |
| primary-600 / 700(hover) / 800 | `#2250df` / `#1a40b5` / `#13318d` |
| 本文 `text-body` | `#3d4b5f` |
| 見出し | `slate-900` |
| 補足 | `slate-500` |
| ページ背景 | `gray-50` |
| 面(カード・パネル) | `white` + `border-slate-200` |
| 成功(上がり) | `emerald-*` |
| 注意(持ち時間・脱落の通知) | `amber-*` |
| 危険(強制敗北・自滅の警告) | `red-*` |
| スート ♥♦ | `red-600`(白地で 4.8:1) |
| スート ♠♣ | `slate-900` |

禁止: `text-black`、`bg-blue-*` / `bg-indigo-*`、`bg-green-*`(→ emerald)、`bg-yellow-*`(→ amber)。

### Typography

フォント: `Inter, Hiragino Sans, Hiragino Kaku Gothic ProN, Noto Sans JP, Yu Gothic UI, Meiryo, sans-serif`
(Webフォントは読み込まない。初回表示を軽くするため)

| クラス | サイズ / 行間 | 用途 |
|---|---|---|
| `text-xxs` | 10px / 1.4 | カード上の効果名、盤面のランク見出し |
| `text-xs` | 13px / 1.4 | バッジ、補足、相手の情報 |
| `text-sm` | 15px / 1.7 | パネルの説明、ログ、ボタン(S) |
| `text-base` | 18px / 2.0 | 本文 |
| `text-2xl` / `text-3xl` | 26px / 32px | タイトル(モバイル / デスクトップ) |

`font-light` と `tracking-tight` は使わない。ゲーム画面の密なエリアは `leading-normal` で行間を戻す。

### Spacing / Radius / Elevation

- 4px グリッド(8の倍数を推奨)
- `rounded-lg` = ボタン・手札のカード・入力欄 / `rounded-xl` = パネル・ダイアログ / `rounded-md` = 盤面のマス / `rounded-full` = バッジ
- 影は `shadow-sm` 〜 `shadow-md`。`shadow-xl` はダイアログのみ

### Motion

| トークン | 値 | 用途 |
|---|---|---|
| fast | 150ms | hover、色の変化 |
| normal | 200ms | 通知の出現、フェード |
| slow | 250〜350ms | カードが手札から場へ移動する(`[0.22,1,0.36,1]`) |
| land | spring(stiffness 520 / damping 20) | カードの登場・着地の弾み |
| cutin | 1100ms(Qボンバー・上がり・終了は 1400ms)/ 控えめ 800ms | 効果発動のカットイン |
| minor | 900ms / 控えめ 700ms | 「あなたの番」「スキップ」の知らせ |

- 通常の UI(hover・パネル・通知)は 300ms 以内。演出レイヤー(§2)だけ長い動きを許す
- **スマホで重くしないための規則**
  - 動かすのは `transform` と `opacity` だけ。`filter`・`box-shadow`・`width` などは動かさない
    (タイマーのバーも width ではなく `scaleX`)
  - 演出は CSS アニメーション(`styles.css` の `fx-*`)か Web Animations で動かし、React を毎フレーム再描画しない
  - 常時ループは、手番の席の枠(opacity)と操作パネル上端の光(transform)、待っている間の3つの点(transform)だけ
  - 粒は最大48個。コア数4以下・メモリ2GB以下・省データ設定の端末では半分にし、既定の演出を「控えめ」にする
  - カットインは1つずつ順番に出し、待ち行列は3件まで(上がり・脱落・終了は捨てない)。裏のタブでは溜めない
- 演出の量はヘッダーの「演出: 豪華 / 控えめ / オフ / ドパガキ」で切り替えられる(`localStorage` に保存、`<html data-fx>` に反映)。
  控えめでは閃光・衝撃波・粒・場の揺れ・キラ・放射線を出さず、カットインを短くする。
  オフではカットインも吹き出しも画面切り替えの幕も出さず、時間差も付けずに動きを止める
- **細かい動き**(yui540/css-animations(MIT)のモーションを参考にした、`styles.css` の「細かい動き」)
  - ぷるん(`fx-jelly-in`): 0 → 縦横がずれて膨らむ → 戻る。選択のチェック・出せるマスの印・通知のアイコン・バッジ
  - 手札のカードを選んだ瞬間は、Motion の scaleX / scaleY でつぶれて伸びて戻る。hover では少し傾ける
  - 画面の切り替え(`ScreenWipe`): 2色の幕が5本の帯で時間差に抜ける。画面・対戦(ラウンド)が変わるたび
  - 文字: タイトルは1文字ずつ落ちて弾む(`fx-letter`)。カットインの見出しは帯が開いてから1文字ずつ跳ねる(`fx-char`)。
    分けた文字は `aria-hidden` にして、元の文を `sr-only` で添える
  - カットインの帯の下に淡い帯を先に開いて後から閉じる(2層のワイプ)。上がり・終了・ジョーカーではキラを散らす
  - 効果のあるカードの着地で、波紋に加えて放射状の線を8本飛ばす
  - 手番が回ってきた席と「あなた」は小さく跳ねる。パスが減ったら残りの数を揺らし、0なら赤にする
  - 結果の順位は上から落ちて弾み、1位にキラ。通知は上から落ちて弾み、ダイアログは下から弾んで出る
  - 塗りのボタンは hover で光が走る(ループしない)
- **ドパガキ(ネタ枠)は、上の「軽さの規則」の例外**。派手にするモードで、端末の性能は考慮しない
  - 自分で選んだときだけなる(既定値にも、低性能端末・`prefers-reduced-motion` の自動判定にもしない)。
    切り替えたときに「光の点滅と音が多いモードです」と知らせる
  - **ふだんは静かにしておき、きっかけがあったときにだけ一気に騒がしくする**(静と動の差)。常に出し続ける飾りは置かない
  - 画面隅の POWER: 誰かがカードを出すたびに「×〇倍!!」が出て、100 × 倍率 が足される(対戦が終わるまで増え続ける)。
    倍率は、自分のカードが 2 のコンボ乗 × チェイン(効果のあるカードは3倍)、相手のカードがチェイン ×(自分のコンボ+1)。
    倍率も POWER も、大きくなるほど大きく派手に出す(万・億・兆…と単位が上がる)。対戦中に出したままにするのは、この数字だけ
  - コンボ: 自分が出し続けた数(COMBO。ランク C〜GOD)と、場に続けて出た数(CHAIN)。
    コンボが2から表示し、切れたら「COMBO BREAK」を出して消す。どれも勝敗に関係のない飾り
  - 暗転: 自分のカードでたまに(約14%)真っ暗になって音も止まり、1秒後に明けて上乗せの倍率(10〜7777倍)が出る
  - FEVER(コンボ5から。8で超、12で神): 四辺の電飾・集中線・虹色のボタンが付き、コンボが切れると消える。
    電飾と集中線は、大きな効果のカットイン・リーチ・弾け飛ぶ演出の間にも一時的に出す
  - 盤面・手札が弾け飛ぶ: 暗くして溜めてから外へ弾け、回りながら元に戻る。Qボンバー(盤面)、GAME SET・コンボの節目(盤面と手札)、
    PUSH が溜まり切ったとき(手札)
  - PUSH: 自分の番に出るボタン。ゲームは進まず、押すたびに音が高くなって輪が溜まり、10回で手札が弾け飛ぶ
  - ほかに、褒め言葉・倍率の数字・着地ごとの紙吹雪・押した位置の火花、出せるカードの縁の色、リーチ(残り1枚)、
    カードの群れ・巨大な 7 や爆弾の落下、暗転からの「勝ち抜け!!」「優勝!!」。カードの効果・自分の番・脱落にも音を鳴らす
  - カードゲームと関係のない題材(スロットのリールや出玉など)は持ち込まない
  - 色・影・背景も動かし、粒の数(3倍、端末による半減なし)も制限しない。紙吹雪は canvas-confetti(ISC)
  - 実装は `components/fx/dopa/`・`fx/dopa.ts`・`dopa.css` に分け、選んだときに初めて読み込む(ふだんの読み込みを重くしない)
  - 画面全体を1秒に3回を超えて明滅させない(光過敏)
- 演出は見た目だけのもの(`aria-hidden`)。同じ内容は通知とログで読み上げる
- `prefers-reduced-motion` の端末では、自分で選ぶまで演出を「オフ」にする。自分で豪華・控えめを選んだら、
  OS の設定より優先する(Motion の `reducedMotion` も演出の量に合わせる)

## 4. Components

### Button(melta Quick Reference)

| 種類 | クラスの要点 | 使う場面 |
|---|---|---|
| primary | `bg-primary-500 text-white hover:bg-primary-700` | 出す、宣言する、渡す、開始 |
| secondary | `bg-white border border-slate-200 text-slate-700` | パス、スキップ、もらわない |
| danger | `bg-red-600 text-white` | 脱落するパス、禁止アガリになる手 |
| subtle | `text-slate-700 hover:bg-gray-50` | ルール、やめる |

高さ: モバイル `h-11`(44px)/ `md:h-10`。同じ見た目のボタンを並べない(主 + 副の組み合わせにする)。

### PlayingCard

- 面: `bg-white border border-slate-200 rounded-lg shadow-sm`
- 手札サイズ: `w-11 h-16`(モバイル)/ `w-14 h-20`(md〜)
- 左上にランク、中央にスート、下に効果名(`text-xxs text-slate-500`、例: 8切り)
- **選択中**: 8px 持ち上げ + `ring-2 ring-primary-500`。`aria-pressed` を付ける
- **出せない**: 不透明度を下げ、読み上げ用に「今は出せません」を付ける(色だけで伝えない)
- **公開中**(砂嵐などに使った): 右上に「公開」バッジ

### Board(場)

- 4行(スート)× 13列(A〜K)の CSS Grid。行の先頭にスート記号、上にランク見出し
- 空きマス: `border-dashed border-slate-200`
- 置かれたマス: 小さいカード。**強制配置**(Qボンバー、10捨てなど)は `bg-slate-50 border-slate-300` + 読み上げで「強制」
- **出せる位置のプレビュー**: 選んだカードのマスを `border-2 border-primary-500 bg-primary-50`
- 盤面は表示専用。操作は手札とパネルのボタンで行う(小さいマスをタップさせない = 44px 規則を守る)
- 各行に読み上げ用の要約(例: 「スペード: 5, 6, 7, 8 が場にある」)を付ける

### OpponentSeat(対戦相手)

- `rounded-xl border bg-white px-3 py-2 shadow-sm`
- 名前、手札の枚数、パスの残り、スキップ数、状態バッジ、公開中のカード
- **手番**: `border-primary-500 ring-2 ring-primary-500/30` + 「手番」バッジ(色 + テキスト)

### DecisionPanel

画面下部に固定。今あなたが答えるべきことを1つだけ表示する。

- 見出し(`text-sm font-semibold`)+ 説明 + ボタン
- 自滅や禁止アガリになる選択肢には、赤い警告(アイコン + 文章)を出す
- 他の人の入力待ちは `bg-gray-50` のテキストで表示する(スピナーは使わない)

### TimerBar

- melta Progress(`h-2 rounded-full bg-slate-200`)
- 基本時間は `bg-primary-500`、持ち時間に入ったら `bg-amber-500` + 「持ち時間 ○秒」の文字

### Toast

- 右上(md〜)/ 上中央(モバイル)。最大5件
- 効果の発動(8切り、Qボンバー、ジョーカーなど): info。上がり: success。脱落・強制敗北: amber
- ゲームの通知は5秒で自動消去。操作が拒否されたエラーは手動で閉じるまで残す
- 通知だけに頼らず、同じ内容をログにも残す

### Dialog

melta Modal に従う。`role="dialog"`、`aria-modal`、見出し、閉じるボタン、Esc、オーバーレイクリック、
フォーカストラップ、閉じたらフォーカスを戻す。使うのはルール、結果、対戦をやめる確認のみ。

**ゲーム進行に必要な選択(7渡し、Qのランクなど)はダイアログにしない。** 閉じられては困るうえ、
盤面を見ながら選ぶ必要があるため、DecisionPanel に出す。

## 6. melta UI から意図的に外れる点

| melta のルール | このゲームでの扱い | 理由 |
|---|---|---|
| 時間制限のある操作を設けない(A11Y_NO_TIME_LIMIT) | 雀魂式の制限時間を設ける | ゲームルール(docs/RULES.md §4-5)。残り時間を常に文字でも表示し、時間切れの挙動を仕様で明示する |
| 1画面3色まで | スートの赤を追加 | トランプの内容そのもの。UIの装飾色には使わない |
| 本文 18px / 行間 2.0 | ゲーム画面は `leading-normal` で密にする | 盤面と手札を1画面に収めるため。タイトル画面の本文は melta どおり |
| モーダルは3つの閉じる経路を持つ | 進行に必要な選択はモーダルにしない | 閉じられない選択をモーダルにすると規則と矛盾するため、パネルで扱う |
| モーションは 300ms 以内、ループ・bounce・spin なし | 演出レイヤーだけ長いカットイン・弾み・回転・紙吹雪を使う | ゲームの盛り上がりのため。§3 Motion の軽さの規則と「控えめ」設定で、スマホの負荷と見やすさを保つ |
